# Advanced Numeric Pattern Generator

## About the Project
The Advanced Numeric Pattern Generator is a Python-based program that generates a symmetrical numerical pattern based on the number of rows entered by the user.

## Objectives
- Accept the number of rows from the user.
- Generate a numerical pattern.
- Use nested loops for pattern generation.
- Display the pattern in a properly aligned format.

## Concepts Used
- Variables and data types
- Nested loops
- For loop
- Range function
- Pattern generation

## How the Program Works
1. The user enters the number of rows.
2. The program uses an outer loop to control the rows.
3. Inner loops generate spaces and numerical values.
4. The numbers are arranged symmetrically.
5. The final numerical pattern is displayed.

## Conclusion
This project demonstrates the use of nested loops and pattern generation techniques in Python programming.
